# Sridhar Futuristic AI Portfolio

## 1. Frontend only

Open `index.html` with VS Code Live Server.

## 2. Backend

Open the terminal inside this folder:

```powershell
npm install
node server.js
```

Open:

```text
http://localhost:3000
```

## 3. Profile photo

Replace:

```text
images/profile.jpeg
```

with your own image. Keep the exact filename, or update the image path in `index.html`.

## 4. Important

Do not put private AI API keys inside `index.html` or `script.js`.
Use `.env` and connect the real AI provider through `server.js`.
